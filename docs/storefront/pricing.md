# repomap is free

Every current capability is free and MIT licensed: code graph, search, call
paths, change impact, interactive graph UI, and multi-repository workspaces.
No licence or paid plan is required, and no new Team order or device claim is
available.

- [Quickstart](https://sylphxai.github.io/repomap/guide/quickstart)
- [MCP tools](https://sylphxai.github.io/repomap/reference/tools)
- [Graph UI and export](https://sylphxai.github.io/repomap/guide/ui)
- [Benchmarks](https://sylphxai.github.io/repomap/benchmarks)

If you have an older Team licence, use [licence recovery](recover.md) to
retrieve it. Existing licences and recovery records are not deleted.
